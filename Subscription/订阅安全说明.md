# 私有订阅安全流程

生成脚本只会写入 VPS 本地目录 /var/lib/surge-subscription/Surge.conf，目录为 0700、文件为 0600，并且只接受 root 所有且权限为 0600 的节点凭据文件。脚本不会开放端口、启动 Web 服务、打印链接或上传内容。

## 自动更新

若要让 Surge 自动更新，可在运行生成脚本时由 root 提供 SUBSCRIPTION_URL。该 URL 必须是你已经部署好的 HTTPS 私有入口，并且应同时满足：

1. 使用至少 32 字节随机路径令牌，令牌不可复用、不可写进 GitHub。
2. 再增加一层访问控制，例如 Caddy Basic Auth、Cloudflare Access 或 mTLS。
3. 仅让反向代理进程读取订阅文件；不要用全局可读静态目录。
4. 证书有效、自动续签，且只开放反向代理所需端口。
5. 链接一旦疑似泄漏，立即更换路径令牌和所有节点密码，再重新生成订阅。

若未设置 SUBSCRIPTION_URL，生成的文件仍可由 root 通过安全方式导入 Surge，但不含托管更新头。VLESS Reality 保持不变，且不会被加入本 Surge 订阅，因为 Surge iOS 不支持 VLESS 策略类型。
