# Surge 分流规则

面向 Surge iOS / macOS 的可组合分流规则。规则按服务类别拆分，可单独在 `[Rule]` 中以 `RULE-SET` 调用，也可直接使用 `Surge/配置/主规则.conf` 的完整规则顺序。

## 使用方式

将 [主规则.conf](Surge/配置/主规则.conf) 中的 `[Rule]` 内容复制到你的 Surge 配置，替换原有的 `[Rule]` 区块。配置要求存在名为 `节点选择` 的策略组；所有海外服务默认使用该策略组，国内服务直连，广告请求拒绝。

若你希望 Netflix、Disney+ 等使用不同节点，可将主规则中对应的 `节点选择` 改为你自己的策略组名称。

## 规则优先级

1. 广告拦截
2. 指定流媒体与海外服务
3. 国内直连
4. 中国 GeoIP 直连
5. 未命中流量交给 `节点选择`

规则顺序不可随意交换：Surge 从上至下首次命中即停止匹配。

## 目录

- `Surge/规则/`：可独立引用的分类规则集
- `Surge/配置/主规则.conf`：引用全部规则集的推荐顺序
- `.github/workflows/规则校验.yml`：每次提交自动检查规则格式

## 上游参考

国内直连与广告基础规则使用 [blackmatrix7/ios_rule_script](https://github.com/blackmatrix7/ios_rule_script) 的 Surge 规则集。该仓库仅维护自己的补充规则和组合逻辑，不复制其大规模规则数据。

## 注意

- 广告规则可能影响少数依赖广告域名的应用；若某应用异常，先在 Surge 日志中确认被拦截域名后再添加例外。
- App 内 YouTube 广告不一定能仅靠域名规则屏蔽，不能保证所有广告都可拦截。
- 使用规则前请确认你的网络和服务使用方式符合当地法律及服务条款。
